# Security Policy

## Supported Versions

Currently, only the latest version of this project is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| others  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it privately. Do **not** create a public issue.

Please send an email to the repository maintainers detailing the vulnerability, how to reproduce it, and any potential mitigation strategies. We will try to respond to the report within a reasonable timeframe.

Thank you for helping keep this project secure!
